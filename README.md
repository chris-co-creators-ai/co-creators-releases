# Co-Creators releases

This repository only holds the installers and update feeds for the Co-Creators desktop app. Installed apps check the releases here for updates. There is no source code in this repository.

Download the latest version from the Releases page.

Co-Creators is an independent product. It runs on the Claude Code and Codex programs installed on your own computer, with your own sign-in and subscription, and no proxy in between.
